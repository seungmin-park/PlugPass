== 주변 충전소 검색

조회는 저장된 데이터만 사용하며 외부 API를 호출하지 않는다. dataReady는 전체 수집 성공 이력이 있다는 뜻이며
실시간 상태를 보장하지 않는다. reportedAvailableCount는 호환 충전기의 AVAILABLE 보고 수이고,
접근 조건·최신성은 각 충전기의 필드로 별도 확인해야 한다. 직선거리는 주행거리가 아니다.

=== 충전기 필드

[cols="1,3"]
|===
|필드 |의미
|chargerId |공급자 충전기 번호, 선행 0 보존
|status / rawStatus |정규화 상태와 원본 코드. AVAILABLE은 공급자의 보고이며 이용 가능 보장이 아님
|freshness / reasonCode |RECENT·STALE·UNVERIFIED와 판단 이유
|sourceObservedAt / collectedAt |신뢰 가능한 관측 시각(null 가능) / 우리 서버 수집 시각. UTC offset 포함 ISO 8601
|connectorCode |공급자 커넥터 조합 원본 코드
|useTime / limitYn / limitDetail / note |이용 시간·제한 여부·제한 내용·비고, 미제공은 null
|sourceStatusChangedAtRaw / lastChargingStartedAtRaw / lastChargingEndedAtRaw / chargingStartedAtRaw |원본 시각 문자열. 시간대 미확인으로 변환하지 않으며 관측 시각을 대신하지 않음
|delYn / delDetail |공급자의 삭제 플래그·사유 원본. 현재 수집은 자동 삭제하지 않음
|===

잘못된 검색 입력은 HTTP 400, code INVALID_REQUEST와 fields의 필드별 한국어 메시지로 응답한다.
검색 결과 없음은 HTTP 200과 빈 stations다. 초기 수집 전의 빈 결과는 dataReady=false다.
