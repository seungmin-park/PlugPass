## 사용자 흐름과 책임

```text
충전소 상세 → 충전기 상태·운영 시간·이용 조건·현장 관측 안내
```

공급자의 `statUpdDt`는 상태 변경·통신 이상·복구 시각이며 현장 관측 시각으로 확정할 수 없다. `sourceObservedAt`가 null이면 현장 관측 시각 미제공을 그대로 알린다. `collectedAt`은 서버가 받은 시각이고, `sourceStatusChangedAtRaw`의 시간대는 확인되지 않았으므로 원본 문자열을 보존한다. 화면 표시 정책은 `charging-info/presentation.ts`가 소유하고 상세·지도 패널에서 함께 사용한다. 최신성/추천 판단은 서버 응답을 유지한다. HTTP 응답 필드는 변경하지 않았다.

정상: 구체 조건·제한 없음·실제 관측 시각. 경계: Y만 있음·누락·공백·깨진 시각·빈 비고·삭제 표시. 미래 관측 판정은 서버의 사유 문구를 표시하며 UI가 날짜를 다시 판단하지 않는다. 서버 오류·응답 역전은 기존 상세 Store/검색 회귀가 맡는다.
