== 주변 충전소 검색

조회는 저장된 데이터만 사용하며 외부 API를 호출하지 않는다. dataReady는 전체 수집 성공 이력이 있다는 뜻이며
실시간 상태를 보장하지 않는다. reportedAvailableCount는 호환 충전기의 AVAILABLE 보고 수이고,
접근 조건·최신성은 각 충전기의 필드로 별도 확인해야 한다. 직선거리는 주행거리가 아니다.

=== 충전기 필드

[cols="1,3"]
|===
|필드 |의미
|chargerId |공급자 충전기 번호, 선행 0 보존
|status / rawStatus |정규화 상태와 원본 코드. AVAILABLE은 공급자의 보고이며 이용 가능 보장이 아님
|freshness / reasonCode |RECENT·STALE·UNVERIFIED와 판단 이유
|sourceObservedAt / collectedAt |신뢰 가능한 관측 시각(null 가능) / 우리 서버 수집 시각. UTC offset 포함 ISO 8601
|connectorCode |공급자 커넥터 조합 원본 코드
|useTime / limitYn / limitDetail / note |이용 시간·제한 여부·제한 내용·비고, 미제공은 null
|sourceStatusChangedAtRaw / lastChargingStartedAtRaw / lastChargingEndedAtRaw / chargingStartedAtRaw |원본 시각 문자열. 시간대 미확인으로 변환하지 않으며 관측 시각을 대신하지 않음
|delYn / delDetail |공급자의 삭제 플래그·사유 원본. 현재 수집은 자동 삭제하지 않음
|===

잘못된 검색 입력은 HTTP 400, code INVALID_REQUEST와 fields의 필드별 한국어 메시지로 응답한다.
검색 결과 없음은 HTTP 200과 빈 stations다. 초기 수집 전의 빈 결과는 dataReady=false다.


== 충전소 상세

공급자 ID와 구분되는 내부 충전소 ID로 조회한다. 모든 충전기를 번호순으로 반환한다.
제공되지 않은 관측 시각·운영 정보는 null이며 제한 없음이나 최신 상태로 추측하지 않는다.
관측 시각 누락/미래는 UNVERIFIED, 허용 기간 이하 RECENT, 초과 STALE이다.
원본 시각 문자열은 시간대 미확인으로 UTC 변환하지 않는다.

없는 내부 ID는 HTTP 404, code STATION_NOT_FOUND, message "충전소를 찾을 수 없습니다", fields 빈 객체로 응답한다.

상세 조회는 외부 API 장애 중에도 저장 데이터로 응답한다. 이는 데이터가 최신이라는 보장은 아니다.

== 대체 후보

저장 데이터만 조회한다. 호환 커넥터·반경 조건 뒤에 excludeStationId를 제거하고 후보 규칙을 적용한다.
preferred는 같은 충전기가 AVAILABLE·RECENT이며 명시적 이용/삭제 제한이 없는 후보,
requiresConfirmation은 AVAILABLE·UNVERIFIED 보고다. STALE·UNKNOWN·사용 중·명시적 제한은 excluded에 이유를 남긴다.
미확인 이용 조건·운영 시간은 경고 코드로 보존한다. 운영 시간 원문의 자유 형식은 자동 영업 여부로 해석하지 않는다.
같은 그룹은 직선거리·내부 ID 순서다. limit은 각 그룹의 최대 건수이며 기본20, 최대50이다.
공급자의 관측 시각이 없으므로 현재 실공급자 보고로 preferred를 만들 수 없다. 도착 시 충전 성공을 보장하지 않는다.

== 지도 영역 검색

남쪽 < 북쪽, 서쪽 < 동쪽의 유한 좌표만 허용한다. 각 축 최대1도와 중심~모서리 최대10km를 모두 만족해야 한다.
날짜변경선을 가로지르는 영역은 지원하지 않는다. 영역·호환 커넥터를 먼저 적용하고 중심 직선거리·ID순으로 limit개를 반환한다.
너무 넓으면 조용히 잘라내지 않고 400 fields.areaValid로 확대를 안내한다.

== 주소·장소 검색

키는 서버 환경변수 KAKAO_LOCAL_REST_API_KEY로 설정한다. 키 미설정은 503 PLACE_SEARCH_NOT_CONFIGURED다.
카카오 주소/키워드 API를 각각 1회 요청하며 자동 재시도하지 않는다. 동일 주소·좌표는 합치고 주소 후보 우선 최대10개를 반환한다.
인증 오류503, 호출 제한429, 시간 초과504, 외부 오류/잘못된 응답502로 구분한다. 원문 오류·키를 반환하지 않는다.
위치 후보 선택은 충전소 검색 확정과 별개다. 외부 조회 중 DB 트랜잭션을 열지 않는다.
