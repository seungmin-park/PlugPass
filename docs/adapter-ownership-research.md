## 기술 계약과 구분

커뮤니티는 사용 맥락의 근거다. 어댑터의 지원 규격·차량 지원·제약은 [Tesla 공식 공공 충전 안내](https://www.tesla.com/ko_kr/support/charging/public-charging) 등 제조사 자료로 판단한다. 개인 케이블, 콘센트용 휴대 충전기, 충전 규격 변환 어댑터, 차량 전력을 꺼내 쓰는 V2L은 같은 물건으로 취급하지 않는다. 게시글의 예전 가격·출력·호환성 주장을 최신 계약으로 옮기지 않는다.

현재 Connector는 **충전기 제공 코드→지원 커넥터**만 매핑한다. 사용자의 보유 어댑터나 차량 지원 정보를 아직 모른다. 저장된 실공공 표본은 인천 첫10건=코드06, 마지막6건=코드04이며 코드06은 다중 커넥터,04는DC콤보다. 첫/마지막16건은 임의 표본이므로 충전소 전체 분포나 모든 종류 구비를 증명하지 않는다.

## 다음 개선안

1. 검색에 필요한 것은 충전소의 연결 규격과 **이번에 이용 가능한 내 장비**다. 보유 어댑터를 자동 가정하지 않는다.
2. 기본 입력은 내 차량(국내/수입시장·연식·필요한 차량 지원 확인 포함)과 ‘사용할 어댑터’다. 미등록/모름/없음을 구분한다. 어댑터 직접 선택은 이름·사진/설명과 함께 제공하고 검증된 모델만 호환 범위를 넓힌다.
3. 결과에는 ‘직접 연결’, ‘보유 어댑터 필요’, ‘호환 확인 필요’를 구분한다. `어댑터 있음` 단일 boolean으로 모든 커넥터를 허용하지 않는다. 소유와 현재 휴대/사용 의사를 구분한다.
4. 호환 커넥터 여러 종류의 합집합 검색이 필요하다. 동일 chargerId가 다중 규격을 지원해도 대수를 중복 계산하지 않는다. 충전소 전체 빈자리와 내 장비로 사용할 수 있는 빈자리를 구분한다.
5. UI를 바꾸기 전 국내 차주 소규모 사용성 확인으로 어댑터 이름 인지·보유·휴대·실제 사용을 각각 묻는다. 대표성 없는 커뮤니티 게시글로 과반 보유를 단정하지 않는다.

이번 작업은 조사와 후속 계획 반영이다. 차량/어댑터 호환 카탈로그·자동 매핑은 구현하지 않았다. T30/T31 지도·주소 검색에서는 기존 커넥터 계약을 유지한다.
