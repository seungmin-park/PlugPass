# T48 현재 위치 중심 검색·지도 우선 화면

사용자 흐름: 저장된 차량이 있으면 검색 화면 진입 → GPS 한 번 요청 → 좌표와 차량 조건으로 검색 → 지도와 가까운 충전소 목록을 한 화면에 표시. 저장된 차량이 없으면 차량 선택 → GPS 요청 → 결과. 목록에 없는 차량의 수동 커넥터 선택은 제출 시 GPS를 요청한다. 주소 선택·직접 URL은 기존 좌표가 우선하며 GPS를 요청하지 않는다.

```text
차량 조건 (저장값 또는 선택) ─┐
                            ├─ 유효한 검색 조건 → URL → 검색 저장소/API → 지도 + 결과 시트
GPS 성공 좌표 ───────────────┘
  └─ 거부·시간 초과 → 오류 안내 + 재시도·주소 검색 (API 호출 없음)
```

View는 자동 검색을 시작할 조건과 URL 확정을 소유하고, `useCurrentLocation`은 권한 요청·취소·시간 초과를 소유한다. `SearchForm`은 차량·커넥터 호환 조건을 소유한다. 지도는 화면의 현재 검색 영역만 다루며, 서버 검색 기준은 URL로 확정한다.

| 우선 | 시나리오 | 검증 |
| --- | --- | --- |
| 필수 | 저장된 차량, 빈 URL, GPS 허용 | 초기 요청 한 번·검색 API 한 번·지도 및 목록 표시 |
| 필수 | 차량을 처음 선택, GPS 허용 | 추가 검색 버튼 없이 결과 표시 |
| 필수 | GPS 거부·시간 초과 | API 미호출·오류 및 주소 검색 안내 |
| 필수 | 직접 URL·주소 선택 | GPS 미요청·기존 좌표 보존 |
| 필수 | 320px·375px | 지도와 첫 결과의 시각적 연결, 목록 스크롤·가로 넘침 없음 |
| 중요 | 느린 GPS 뒤 주소 선택·화면 이탈 | 이전 위치 응답 무시 |

단위 컴포넌트 검사는 상태 전이와 API 조건을, headless Chromium E2E는 실제 화면 배치와 사용자 경로를 확인한다. 로컬 E2E 명령과 로그는 현재 cmux 보조 pane에서 보이게 실행한다. 사진·평점은 현재 공급자 데이터에 없으므로 표시하지 않는다.

## 위치 실패 안내 근거

Google 지도 도움말은 길찾기에 기기 GPS 활성화와 지도 앱의 위치 권한이 필요하다고 안내한다. Apple은 iPhone의 위치 서비스와 앱별 권한을 별도 설정으로 설명한다. 따라서 PlugPass의 권한 거부 안내는 기기 위치 서비스와 브라우저의 사이트 권한을 함께 확인하도록 한다. MDN의 Geolocation 오류 코드는 권한 거부(1), 위치 확인 불가(2), 시간 초과(3)로 구분된다. 앱은 이 세 경우에 각각 이유를 보여주고 재시도와 주소 검색을 제공한다. 출처: [Google 지도 도움말](https://support.google.com/maps/answer/3273406?hl=en), [Apple 위치 서비스](https://support.apple.com/en-gb/guide/iphone/iph3dd5f9be/27/ios/27), [MDN 오류 코드](https://developer.mozilla.org/en-US/docs/Web/API/GeolocationPositionError).
